## 내용 정리

### 1. 문제

GPT-4V는 장면 전체를 설명하는 태스트는 잘 수행했으나, "그게 정확히 어디 있냐"를 물으면 답을 못 하는 문제 발생.
논문 예시: 개 한 마리, 신호등 몇 개의 위치도 짚어내지 못함.
-> fine-grained visual grounding(세밀한 시각적 지칭) 능력

### 2. 원인

기존에는 모델한테 좌표를 숫자로 말하도록 요청함 -> 논문은 기존 방식이 두 가지를 동시에 망가뜨린다고 판단

- LLM: 자연어 흐름 중간에 정밀한 숫자를 끼워 넣으면 언어 능력에 부정적 영향
- 비전: 비전 인코더가 가진 공간 정보가 텍스트 토큰을 거치면서 소실됨

-> 텍스트 프롬프트를 고치는 대신 입력 이미지 자체를 고치자는 쪽으로 방법 탐색


### 3. 선행 연구의 한계

이미지 위에 빨간 동그라미, 하이라이트, 화살표 같은 표식을 추가하는 기존 시각적 프롬프팅의 한계:

- 객체를 한두 개밖에 못 가리킴
- 마커가 not speakable함. 빨간 동그라미를 문장 안에서 뭐라고 부를지 지정하기 어려움

-> 마커는 눈으로 보이면서 동시에 말로도 쓸 수 있어야함.
-> 숫자와 알파벳 사용

### 4. 방법: 3단계

1. **영역 분할**: 기성 세그멘테이션 모델로 이미지를 K개 영역으로 쪼갬
   - 정밀도 → MaskDINO / 오픈 보캐블러리 → SEEM / 다양한 granularity → SAM, Semantic-SAM
   - "의자"뿐 아니라 "의자 등받이"도 잡을 수 있어야 해서 granularity가 중요
2. **마커 생성**: 각 영역에 번호를 찍음
   - 영숫자를 주로 쓰고(자리 적게 차지, OCR로 읽힘) 박스랑 마스크 경계선을 보조로 추가
   - 숫자 많은 이미지엔 숫자 마커를 피하는 식으로 이미지마다 마커 타입을 바꿔야 하는데, 자동 선택은 향후 과제로 남김
3. **프롬프트**: 평소처럼 질문 

마커 위치를 중심에 찍으면 밀집 영역에서 겹치거나 오목한 영역에서 바깥에 찍히는 문제가 발생 -> 마커 위치 할당 알고리즘

- 면적 오름차순으로 정렬해서 작은 영역부터 처리
- 앞 영역이 이미 덮은 부분은 제외
- distance transform으로 경계에서 가장 먼 지점에 마커 배치



### 5. 창발적 능력

텍스트로는 마커에 대해 아무것도 알려주지 않았음 (예: 물건마다 번호를 쓴 마킹을 해뒀어. 이걸 확인해봐. -> 이런 프롬프팅 X), GPT-4V가 마커의 의미를 알아서 이해하고 언제 어떻게 연결할지도 스스로 판단함.
이런 능력을 emergent ability(창발적 능력)라고 명명, 다른 LMM들은 사진을 보고 마커를 말하지 못함. 해당 능력은  GPT-4V에서만 나타남. (2023년 기준)

### 6. 결과

RefCOCOg REC (ACC@0.5, 제로샷)

| 방식 | 점수 |
|---|---|
| GPT-4V 좌표 직접 생성 | 25.7 |
| GPT-4V + SoM | 86.4 |

이미지에 숫자만 추가하고 프롬프팅 차이가 없었음에도 큰 개선, 해당 태스크로 파인튜닝된 PolyFormer, Grounding DINO랑 오픈소스 LMM(LLaVA-1.5, Shikra, MiniGPT-v2, Ferret)을 제로샷으로 이김.


### 7. Ablation

| 조건 | 결과 |
|---|---|
| 숫자 + 마스크 | 84.4 (Flickr30K R@1) |
| 숫자 + 마스크 + 박스 | 89.2 |
| MaskDINO 예측 마스크 | 75.6 (RefCOCOg mIoU) |
| 정답 마스크 | 90.1 |

박스만 추가 -> 5포인트 가까이 상승, 정답 마스크 사용 -> 14.5포인트나 상승.
-> SoM이 LLM을 가이드할 수 있으나, 성능은 세그멘테이션 품질이 정한다고 주장함.

### 8. 한계

논문이 인정한 것
- 마커 타입 자동 선택 미해결
- 세그멘테이션 성능에 의존
- GPT-4V에서만 작동

이후 생각해 볼 부분
- 2026년 지금 모델들에서도 여전히 GPT-4V 전용 현상일지
- 실험이 전부 일반 사진(COCO, Flickr30K, ADE20K, DAVIS)인데, 선화 다이어그램이나 설계도에서도 통할지
